# 用户模块实现

本次迁移覆盖 Go 版 `account` 模块的六个接口，沿用 Java 工程的 Controller / Service / Mapper 分层、MyBatis-Plus、BCrypt、JJWT 和 Redisson。

## 接口

| 方法 | 路径 | 成功状态 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/users` | 201 | 注册账号，事务内创建关系初始统计 |
| POST | `/api/sessions` | 200 | 校验账号密码，签发 900 秒访问令牌 |
| DELETE | `/api/sessions/current` | 204 | 吊销当前令牌，无响应体 |
| GET | `/api/users/me` | 200 | 读取当前用户资料和统计 |
| PATCH | `/api/users/me` | 200 | 修改昵称、头像、简介 |
| GET | `/api/users/{userId}` | 200 | 匿名读取公开资料，不返回账号、角色、状态 |

除 204 外均使用 `ApiResponse` 包装，业务字段保持原 Go 接口的 snake_case。前端 `apiRequest` 已适配解包。

## 幂等性决策

无需为 user 模块引入通用幂等注解、幂等记录表、Redis 请求锁或 `Idempotency-Key`。

- **注册**：直接插入，由 `uk_account` 保证全局唯一，包含并发和已注销的账号。重复返回 409，不能用注册重试读取现有账号资料。唯一约束保证不会重复创建，但并不提供成功响应重放。
- **资料更新**：只对显式传入的非 null 字段做赋值。头像和简介允许清空，昵称不允许。连续重复同一 PATCH 后业务状态相同，不会追加资源。不同字段的并发修改不会相互覆盖；同一字段是最后写入生效。旧请求跨越后续编辑再次到达时仍可能覆盖新值，当前不提供版本冲突检测。
- **登录**：每次成功都签发新的 jti；不复用缓存中的 token。
- **登出**：Redis 按 jti 执行 `SET NX`，TTL 等于剩余有效期。首次 204，随后同一 token 的受保护请求（包括重复登出）返回 401；吊销状态不变，也不延长 TTL。

如果以后注册产生发券、欢迎消息等独立副作用，应为相应记录建立唯一约束，或采用事务消息与消费去重；只有确实需要重放首次结果时再引入请求级幂等协议。

## 实现边界

- 注册创建 `account` 和 `user_relation_stat` 的操作在同一事务中，任一步失败均回滚。
- 密码与 Go 版保持一致：去除首尾空白，只保存 BCrypt 哈希。限制 64 字符且 UTF-8 不超过 72 字节，避免多字节密码触发底层异常。
- 登录时账号不存在和密码错误均返回 401 / 10012；不存在的账号也执行 BCrypt 校验。正确密码但状态异常返回 403 / 10013。
- 主页统计在 Service 内由三个 MyBatis-Plus 单表查询组装（账号、`user_relation_stat` 各按主键读取，作品数 `selectCount` 统计 `status = 2` 的上线视频），`UserMapper` 不含自定义 SQL；账号查询显式排除 `status = 3` 的已注销账号，主页和资料更新对注销账号返回 404。关注/粉丝数统计行缺失时按 0 处理，负数归零。`UserRelationStat` 实体与 Mapper 属 user 模块；`Video` 仅映射统计所需列，放在 `modules/video`，待该模块实现时补全。关系模块实现后需在事务内维护统计表。
- JWT 校验签名、HS256、issuer、有效期、令牌类型、正数 uid 和非空 jti；鉴权结束清理线程上下文。Redis 故障不放行受保护请求，避免已吊销令牌重新生效。
- 基础配置按职责组织：`AuthenticationConfiguration` 提供 JWT、黑名单和密码编码器，`WebMvcConfiguration` 管理鉴权拦截器、跨域和上传资源映射，`RedissonConfiguration` 提供 Redis 客户端，`MybatisPlusConfiguration` 提供 Mapper 扫描、分页、防误更新及时间填充。`User` 的时间字段已标注填充策略；实体继续使用手写 Builder。
- 数据库字段与 `../../sql/schema.sql` 一致，本次没有数据库结构迁移。

## 验证

```bash
./mvnw clean test
```

测试使用 H2 的 MySQL 模式执行生产建表语句中相关的三个表，并运行真实 Mapper、Service 事务和 MVC 鉴权链。Redis 客户端使用测试替身，普通测试不需要外部数据库或缓存。

覆盖注册与 BCrypt、并发重复注册、统计写入失败回滚、登录状态与错误码、参数边界、部分更新与重复赋值、公开字段隔离、注销账号不可见、作品统计、登出 TTL 与 token 隔离，以及 Redis 故障时拒绝访问。H2 不能替代部署环境中的 MySQL / Redis 联调。
